## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockMintPro.git`
2. `cd BlockMintPro`
3. Install in editable mode: `pip install -e .`

## Configuration

BlockMintPro is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
